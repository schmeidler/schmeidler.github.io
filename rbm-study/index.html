Restricted Boltzmann Machines under extreme label scarcity

Overview

Can unsupervised pretraining help when only a handful of diagnostic labels are available for training? In this experiment, a Restricted Boltzmann Machine (RBM) first learns from unlabelled morphology profiles. Its representation is then used for classification with only a few benign and malignant examples.

With two to three labels per class, the RBM is slightly ahead of direct logistic regression on average. With five to ten labels, this advantage is no longer observed. This result applies to this dataset and the model configurations examined here.

What “unlabelled” means here

The features are available, but the diagnoses are hidden during pretraining. The RBM does not generate new labels. The final classifier receives genuine diagnostic labels.

01

Results

With two labelled cases per class, the RBM representation achieves a mean AUROC of 0.9691; direct logistic regression achieves 0.9582. The difference is 0.0109. As the number of labels increases, direct logistic regression improves in particular, while the RBM curve remains largely flat.

How to read the metrics

AUROC measures ranking performance, not accuracy. Average Precision (AP) summarises the precision–recall curve. Positive class: malignant lesion. 3

Methods

The Wisconsin Diagnostic Breast Cancer dataset (WDBC) contains 569 cases with 30 numeric cell-nucleus features. These features were computed from digitised fine-needle aspirates of breast lesions. This analysis uses the tabular features, not the original images. 1

For each split, 426 cases form the training pool and 143 are held out as test cases. Scaling, discretisation and representation learning are fitted only within the training pool. The test cases are also excluded from unsupervised pretraining.

30 morphology features → Quantile encoding → RBM with 32 units → Logistic regression

Continuous features are divided into up to five quantile bins and binarised. A Bernoulli RBM learns joint patterns in these inputs without using diagnostic labels. Its activation probabilities are then used as 32 features for a regularised logistic regression. 2

h j (x) = P(H j = 1 | x) = σ(b j + w j T x)

The classifier receives two, three, five or ten examples of each class. Each configuration is evaluated with 50 random label draws per split. Comparisons include direct continuous logistic regression, binned logistic regression, SVD, autoencoder and RBM. SVD and the autoencoder use 32 latent dimensions, as does the RBM.

Experimental protocol and model parameters
Data split
Ten stratified random 75/25 splits, seeds 1000–1009. Each contains 426 training and 143 test cases; each test set has 90 benign and 53 malignant cases. No case identifier is used as an input.
Label selection
50 balanced draws per label budget and split, with no duplicate cases within a draw. Paired across models, not nested across label budgets.
Direct logistic regression
StandardScaler on all unlabelled training cases. 30 continuous features.
Discretisation
KBinsDiscretizer(n_bins=5, strategy='quantile') , one-hot encoding; fitted exclusively on the training pool.
SVD
32 components on the binary input; subsequently standardised using the training pool.
RBM
32 hidden units, learning rate 0.05, batch size 32, 50 epochs, seeds 2000–2009. Persistent Contrastive Divergence in scikit-learn. 2
Autoencoder
Sigmoid encoder with 32 dimensions and a sigmoid decoder. Binary cross-entropy, Adam, learning rate 0.01, weight decay 10 −5 , 250 full-batch epochs. One fixed configuration; no comprehensive architecture comparison.
Classifier
All variants use LogisticRegression(C=0.1, solver='liblinear', max_iter=1000) . RBM and autoencoder activations receive no further standardisation. The same C value does not imply the same effective regularisation when feature scales differ.
Evaluation
10,000 stored model runs: five models × four label budgets × ten splits × 50 draws. Average Precision was calculated with average_precision_score ; the historical export column is named auprc . 3

Interpretation and limitations

The result is consistent with a benefit from unsupervised pretraining under extreme label scarcity. The effect size is limited, however. From five labels per class onward, direct logistic regression already has a higher mean AUROC than the RBM. The study therefore does not establish a general RBM advantage or superiority over autoencoders.

Label scarcity is simulated. To draw a balanced labelled set, candidate class identities must already be known. Four released labels therefore do not automatically correspond to the practical effort of diagnosing four arbitrary cases. No actual reduction in annotation time was measured.

WDBC is a small, historical sample. Repeated splits of the same cases are not a substitute for external validation. Discretisation, scaling and fixed regularisation also affect the model comparison. Transfer to other laboratories, specimens or tumour types was not studied.

The dataset was selected as a positive example after several exploratory dataset and task trials. This selection increases the risk of optimistic findings.

The basic idea is not new either: RBM-based methods for learning from few labels in breast-imaging diagnosis have been studied previously. The purpose of this small project is a transparent comparison on tabular data, including the conditions under which the observed advantage disappears. 4

Conclusion

A small niche for an older model: with two to three labels per class, a mean advantage is visible. More labelled examples reduce the difference and eventually reverse it.
